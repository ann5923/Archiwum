# Źródła edytowalnych zasobów
Python 3 + Pillow + NumPy. Uruchamiaj skrypty z folderu 06_ZRODLA:
python tower_v2.py — modele, tekstury, rendery.
python tower_maps.py — struktury NBT, opis bloków i rendery.
python tower_story.py — dokumenty i prompt.
Skrypty nadpisują odpowiadające im pliki w tej paczce. Zrób kopię przed ręcznymi zmianami. Nie odtwarzają ilustracji AI, których prompty są w 05_PROMPT/PROMPTY_ILUSTRACJI.json. Żaden z tych skryptów nie generuje kodu moda Fabric ani JAR.
